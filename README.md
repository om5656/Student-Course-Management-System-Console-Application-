# Student Course Management System

## Description
A C++ console application for managing students and their enrolled courses.  
It allows adding, removing, searching, and displaying students, enrolling them in courses, and sorting by GPA.  

## Features
- Add Student (ID, Name, GPA)
- Remove Student by ID
- Search Student by ID
- Display All Students
- Enroll Student in Course
- Show Student Courses
- Sort Students by GPA

## Requirements
- C++11 or higher
- Standard C++ compiler (g++, Visual Studio, Code::Blocks, etc.)
