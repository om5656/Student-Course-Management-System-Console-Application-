# Student Course Management System

## Description

A C++ console application to manage students and their enrolled courses.
The program allows adding, removing, searching, displaying students, enrolling them in courses, and sorting students by GPA.

## Features

* Add Student (ID, Name, GPA)
* Remove Student by ID
* Search Student by ID
* Display All Students
* Enroll Student in Course
* Show Student Courses
* Sort Students by GPA

## Requirements

* C++11 or higher
* Any C++ compiler (g++, Visual Studio, Code::Blocks)

## Project Structure

* `main.cpp` – main program and menu
* `Student.h` – class declarations
* `Student.cpp` – class implementations
* `UML_StudentSystem.png` – UML class diagram

## Compile & Run

```bash
g++ main.cpp Student.cpp -o StudentSystem
./StudentSystem
```
